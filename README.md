# 2026 지능형로봇경진대회 로봇 소프트웨어

ROS 2 Jazzy 기반의 대회용 로봇 소프트웨어입니다. 모터 구동, 센서 연동, 영상 인식, 미션 제어, 운영 GUI를 포함합니다.

| 패키지 | 역할 |
| --- | --- |
| `robot_base` | 모터 제어와 로봇 운동학 |
| `robot_bringup` | 하드웨어·센서 설정과 ROS 2 실행 구성 |
| `robot_vision` | 차선·표지·손 인식 |
| `robot_mission` | 주행 및 추종 미션 상태 관리 |
| `robot_gui` | 상태 모니터링과 미션 조작 |

설치, 빌드, 테스트 및 실행 방법은 [워크스페이스 README](robot_ws/README.md)를 참고하세요.
